# Background music

No audio file is bundled (licensing reasons — royalty-free music can't be
fabricated here). To enable the music toggle:

1. Add your royalty-free track as `wedding-theme.mp3` in this folder.
2. That's it — `index.html` already points `#bgAudio` at
   `assets/audio/wedding-theme.mp3`.

Good sources for royalty-free wedding music: Epidemic Sound, Artlist,
YouTube Audio Library, or a track you've licensed directly.

Until a file is added, the play/pause button still works in the UI but
will show a toast letting the guest know the track is missing.
